# Clustering Analysis and Data Interpretation

---

## 🚀 Project Overview

This project was developed as part of the **Introduction to Artificial Intelligence** course held at the University of Milano-Bicocca (Unimib).

The main objective of the project was to explore and apply various **unsupervised clustering techniques** to two distinct datasets, analyzing the intrinsic structures within the data and proposing meaningful interpretations of the results obtained.

---

## 📋 Core Contents

The project focuses on the application and analysis of two primary clustering algorithms:

1.  **K-Means:** A distance-based partitioning algorithm used to group data.
2.  **DBSCAN (Density-Based Spatial Clustering of Applications with Noise):** A density-based algorithm, effective for identifying arbitrarily shaped clusters and handling noise.

The work includes:
* Data preprocessing and cleaning.
* Application of the models to the two datasets.
* Analysis and visualization of the resulting clusters.
* Critical discussion of evaluation metrics (e.g., Silhouette Score) and interpretation of the identified partitions.
